# Digital Clock & Stopwatch

## Project Overview

The **Digital Clock & Stopwatch** is a simple and interactive web application developed using **HTML, CSS, and JavaScript**. It combines a real-time digital clock with a fully functional stopwatch in a single interface. The digital clock continuously displays the current system time, while the stopwatch allows users to measure elapsed time with start, stop, and reset controls.

This project demonstrates the use of JavaScript timers, DOM manipulation, and responsive web design to create an easy-to-use and visually appealing application.

## Installation

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension (optional but recommended).
4. Open the `index.html` file.
5. Launch the project using Live Server or open it directly in your web browser.

---

## How to Use

1. Open the application in your browser.
2. The digital clock will automatically display the current time.
3. Click the **Start** button to begin the stopwatch.
4. Click the **Stop** button to pause the stopwatch.
5. Click the **Reset** button to set the stopwatch back to `00:00:00`.
